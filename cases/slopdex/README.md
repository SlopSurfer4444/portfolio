# Slopdex — доработка Codex под собственный рабочий процесс

**Мне не хватало возможностей для вложенной работы AI-агентов — я взял открытый код Codex и организовал доработку с помощью самих агентов.**

[Исходный код](https://github.com/SlopSurfer4444/slopdex) · [Обзор изменений и тестов](https://github.com/SlopSurfer4444/slopdex/blob/57644b9e8e7db6501572ba90777fa9f507f285d5/slopdex/REVIEW_GUIDE.md) · [Windows CLI preview](https://github.com/SlopSurfer4444/slopdex/releases/tag/v0.1.0-preview.1)

## Чего не хватало

В больших задачах хотелось оставаться в одной основной беседе, а независимую работу распределять между агентами. При этом агент должен уметь разделить свою задачу дальше, дождаться исполнителей и вернуть собранный результат своему родителю.

Меня интересовало не только количество параллельных агентов. Нужно было сохранять принадлежность задач, правильно возвращать результаты и завершать процессы, когда работа закончена. Так появился Slopdex — самостоятельный эксперимент на базе открытого исходного кода OpenAI Codex.

## Что сделал

Я сформулировал нужный рабочий процесс, координировал AI coding agents, разбирал результаты проверок и проверял вложенную работу на Windows. Агенты помогали с изменениями Rust-кода, тестами, ревью и подготовкой публикации.

В доработанной версии появились настраиваемая глубина вложенности и увеличенная доступная параллельность. Отдельная работа касалась принадлежности дочерних задач, ожидания их завершения, возврата результатов ближайшему родителю, обработки повторных уведомлений и учёта ресурсов.

Рядом с кодом опубликованы инструкции оркестрации: как находить независимые части работы, назначать ответственных за результат и собирать изменения обратно. Программные механизмы и инструкции для модели описаны раздельно.

## Результат

- Опубликованы изменённый исходный код, переносимый патч к закреплённой версии upstream и руководство по ревью.
- Для принятого исходного кандидата зафиксировано прохождение 82 целевых тестов.
- На Windows проверен вложенный сценарий: родитель → координатор → исполнитель, с возвратом промежуточного и итогового результатов.
- Выпущен отдельный Windows x64 CLI preview с инструкцией запуска. Для опубликованной пересборки записаны собственные проверки сборки и автономного запуска.

[Материалы проверок](https://github.com/SlopSurfer4444/slopdex/tree/57644b9e8e7db6501572ba90777fa9f507f285d5/slopdex) позволяют посмотреть конкретные изменения, подтверждённые сценарии и границы эксперимента.

## Почему остановился

Проект начался с личного неудобства и увлёк меня значительно глубже первоначальной задачи. Я дошёл до публичного исходного кода, проверяемого патча и CLI preview, после чего решил остановить дальнейшее развитие: время и лимиты AI-агентов полезнее направить на CommunityHero, Neurobro и другие прикладные проекты.

Slopdex оставлен как инженерный эксперимент и зафиксированный результат. Он показывает, как я подхожу к ограничениям рабочего инструмента: формулирую недостающую возможность, организую реализацию, проверяю её и решаю, стоит ли продолжать инвестиции.

## Основа и мой вклад

OpenAI Codex и исходная архитектура принадлежат upstream-проекту и его участникам. Slopdex — независимая производная версия с собственными доработками, не официальный выпуск OpenAI. Мой вклад — постановка задачи, координация разработки с AI-агентами, интеграция и приёмка изменений.

**Технологии:** Rust, TypeScript, Windows CLI, тесты жизненного цикла агентов и инструкции оркестрации.
