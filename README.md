# Портфолио

Практические проекты в области инфраструктуры, автоматизации и прикладных инструментов.

В кейсах показываю задачу, свои решения, результат и способы его проверки. Использую ИИ для разработки и разбора технических задач; свой вклад и роль ИИ описываю отдельно.

## Проекты

### [CommunityHero — платформа для работы с комментариями](cases/communityhero/README.md)

Из собственной работы комьюнити-менеджером: контекст постов и обсуждений, распознавание видео, знания компаний и подготовка ответов с проверкой человеком. Автоматизация и платформа развивались параллельно и сошлись через адаптер Angry.Space.

**Мой вклад:** продуктовые решения, постановка задач AI coding agents, координация разработки и приёмка по реальной работе.

**Внутри кейса:** история создания, живой интерфейс LikeAvto, локальный Whisper на GPU и общий Rust/PostgreSQL-движок сайта и чата.

[Читать кейс →](cases/communityhero/README.md) · [Исходный код](https://github.com/SlopSurfer4444/CommunityHero-public)

### [Neurobro — AI-ассистент в Telegram](cases/neurobro/README.md)

Ассистент через обычный Telegram-аккаунт: контекст и память, поиск по истории, медиа и инструменты, длительные задачи с сохранением прогресса и отдельной доставкой отчёта.

**Мой вклад:** концепция, требования, архитектурные решения, координация AI coding agents, интеграция и приёмка в реальных группах.

**Эксплуатация:** 24/7 на Windows/WSL — фоновый запуск, сохранение состояния и механизмы восстановления.

**Внутри кейса:** GramJS / MTProto, разделение прав чатов, Python/Node-мост в WSL, восстановление после сбоев и отдельные Rust-прототипы Windows-изоляции.

[Читать кейс →](cases/neurobro/README.md) · [Исходный код](https://github.com/SlopSurfer4444/Neurobro)

### [Офисная инфраструктура и инструменты управления](cases/office-infrastructure/README.md)

Собрал инфраструктуру небольшого офиса: от выбора оборудования и развёртывания серверов до файлового хранилища, печати, управления камерами и эксплуатационной документации. С помощью ИИ разработал панель управления офисом для руководителя, приложение для карт доступа и PDF-компоновщик для широкоформатной печати.

**Масштаб:** 5 виртуальных машин · 9 камер · PDF-компоновщик на 7 настольных ПК · 13 документов для эксплуатации.

**Мой вклад:** требования, подбор и закупка оборудования, сборка, интеграция, постановка задач на разработку и приёмка на реальном оборудовании.

**Внутри кейса:** проверка фактического результата команд, работа со старым USB-плоттером, права пользователей, шифрование папок NAS и проверка зашифрованного архива.

[Читать кейс →](cases/office-infrastructure/README.md) · [Архитектура](cases/office-infrastructure/docs/architecture.md) · [Приложения](cases/office-infrastructure/docs/applications.md) · [Проверка результата](cases/office-infrastructure/docs/operations.md)

**Код приложений:** [Менеджер карт СКУД · C# / WPF](https://github.com/SlopSurfer4444/skud-card-manager) · [PDF-компоновщик · Python](https://github.com/SlopSurfer4444/plotter-composer). Каждый проект находится в отдельном репозитории с инструкциями и автономными тестами.
