## Как я разрабатываю

**Настраиваю агентную среду, а не управляю каждым шагом.** Настроил Codex через глобальные правила и skills, которые дорабатываю по результатам практики. Моя роль — задать цель, ограничения и критерии результата, проверить поведение решения в рабочих сценариях и принять итог.

**Организацию и выполнение работы делегирую моделям.** Координатор сам декомпозирует задачу, выбирает исполнителей, сводит результаты и пересматривает план. Агенты исследуют код, предлагают технические решения, реализуют изменения, запускают тесты и выполняют ревью.

Не задаю обязательный pipeline или фиксированное число агентов: координатор выбирает между одним исполнителем, параллельными ветками и рекурсивной делегацией. На практике обычно работают несколько сильных агентов. DAG и рекурсия — инструменты, а не обязательный шаблон. Фиксированные конвейеры использую для повторяемых процессов внутри продукта, например обработки комментариев.
