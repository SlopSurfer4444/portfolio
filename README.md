### CommunityHero — работа с комментариями и AI-черновиками

Коллеги используют инструмент для обработки комментариев LikeAvto через адаптер Angry.Space. В одном интерфейсе — контекст публикации и обсуждения, черновик ответа и проверка человеком перед отправкой.

Из собственной работы комьюнити-менеджером я перенёс в продукт контекст веток, правила компаний и распознавание речи из видео. Платформа и автоматизация развивались параллельно; адаптер связал их для раннего использования.

### Офисная инфраструктура и инструменты управления

Подобрал оборудование и организовал закупку, собрал инфраструктуру и связал файловое хранилище, рабочие места, печать и офисные сервисы. Организовал разработку прикладных инструментов и проверял результат на оборудовании.

Office Control объединяет обзор офиса, просмотр существующих прав на папки, состояние хранилища и резервных копий, управление камерами и журнал. Отдельные приложения помогают работать с картами доступа и готовить PDF для старого USB-плоттера.

**Объём внедрения:** 5 виртуальных машин, 9 камер, PDF-компоновщик на 7 настольных ПК. Подготовлена документация для пользователей и следующего администратора.

### Neurobro — Telegram-ассистент с памятью и длительными задачами

Ассистент через обычный Telegram-аккаунт по GramJS/MTProto: учитывает разговор, ищет по истории, работает с медиа и сохраняет прогресс длительных задач для доставки отчёта.

В проекте я прорабатывал поведение ассистента, разделение прав чатов и восстановление после прерываний. Эксплуатировал его в режиме 24/7 на Windows/WSL с фоновым запуском и сохранением состояния.

[Кейс и схема →](cases/neurobro/README.md) · [Публичный код](https://github.com/SlopSurfer4444/Neurobro)

### Slopdex — эксперимент с рекурсивной работой агентов

Организовал доработку открытого Codex: вложенные агенты, нативное ожидание после завершения хода и возобновление родителя с результатом дочерней работы. Опубликованы исходники, патч, целевые тесты и экспериментальный Windows CLI preview.

Развитие остановлено на опубликованном этапе: время и лимиты направил на прикладные проекты. Это независимая производная версия с сохранением авторства upstream.
